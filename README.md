# Mobile Pause

A small client-side mod that adds a working pause button to the mobile HUD.

The built-in mobile pause button turns into a player-list toggle whenever
you're hosting a game, instead of pausing — the desktop version doesn't have
this problem, since it tells "hosting" and "connected as a client" apart
correctly. This mod adds its own pause button in the top-right corner of the
HUD (mobile only) that works exactly like the desktop pause key: it pauses
while you're playing solo or hosting, and stays hidden if you've joined
someone else's server (same as desktop).

## Install

Import `MobilePause.zip` (or this repo URL) via **Mods → Import Mod** in-game.
